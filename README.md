# IPTV Live — downloads

Google TV / Android TV app that adds your Xtream IPTV channels (with guide) to the Live TV / Live Channels app.

## Install on a Google TV / onn box

1. Install **Downloader** (by AFTVnews) from the Play Store.
2. Allow Downloader to install unknown apps (Settings → Apps → Security & restrictions → Unknown sources).
3. In Downloader, enter code **2967977**
   (or the link `https://github.com/dchtlh3/iptvlive-releases/releases/latest/download/IPTVLive.apk`).
4. Install, open **IPTV Live**, and log in with your Xtream server / username / password.

The code always installs the newest version.
